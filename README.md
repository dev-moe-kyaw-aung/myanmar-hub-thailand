# 🇲🇲 Myanmar Hub Thailand 🇹🇭

Unified super-app for Myanmar people in Thailand, combining **3 flagship modules**:

| Module | Style | Purpose |
|---|---|---|
| 🏆 Golden Journey | Gamified RPG | Life navigator with quests, XP, badges |
| 🛡️ Safe Harbor | Trust & Safety | Health, legal, emergency, documents |
| 🏪 Business Circle | B2B / POS | Shop management, inventory, payroll |

## Stack
- **Next.js 14** (App Router, TypeScript)
- **TailwindCSS** (dark mode)
- **Lucide icons**
- Ready for **Vercel** (auto CI/CD via GitHub Actions)

## Run Locally
```bash
npm install
npm run dev
# open http://localhost:3000
